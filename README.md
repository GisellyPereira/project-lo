# Nutriviva — Site de Nutricionista (Demo)

Site fictício em **Next.js 14 + Tailwind CSS + Framer Motion** para a marca **Nutriviva** (Dra. Lara Monteiro).
Inclui seções de serviços, mídia, ações sociais, depoimentos, planos, FAQ e contato com WhatsApp.

> **Atenção:** Todos os dados são fictícios para demonstração.

## Rodando localmente

```bash
npm install
npm run dev
# abra http://localhost:3000
```

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

As imagens são carregadas via Unsplash/Pexels por URL.
